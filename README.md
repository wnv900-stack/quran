# سَكِينَة — موقع القرآن الكريم والمقالات والتسبيح

موقع عربي باتجاه الكتابة من اليمين إلى اليسار، بتصميم ليلي بألوان بنفسجية ولمسات خضراء مستوحاة من الفيديو المرجعي.

## الأقسام

1. **القرآن الكريم:** استعراض صفحات المصحف الـ604 (تجميع الآيات بحسب صفحات مصحف المدينة عبر الإصدار `quran-uthmani`)، قائمة سور، القفز إلى رقم صفحة، والتشغيل بصوت الشيخ **ماهر المعيقلي**. عند توافر بيانات توقيت متوافقة مع التسجيل ومع كلمات الآية يعرض تمييزًا لحظيًا للكلمة والآية، وإلا يقتصر على الآية ولا يختلق توقيت الكلمات.
2. **مقالات:** مقال وحيد بعنوان «لماذا تفكر في كل شيء أثناء الصلاة؟» بنصه الكامل الذي زوّد به صاحب الموقع.
3. **سبّح:** ستة أذكار، زرّ عد دائري، أهداف سريعة 33 و100 و1000 أو هدف تحدده بنفسك، وحفظ الأعداد على الجهاز نفسه عبر LocalStorage.

## رفع الموقع إلى GitHub ثم Vercel

1. فك ضغط الملف `sakeenah-site.zip`.
2. أنشئ مستودعًا جديدًا على GitHub.
3. ارفع **جميع الملفات والمجلد `api` إلى جذر المستودع** (ليس ملف ZIP نفسه داخل المستودع).
4. افتح [vercel.com](https://vercel.com) واختر **Add New → Project** ثم استورد المستودع من GitHub.
5. اختر **Framework Preset: Other** إذا طُلب منك الاختيار، واترك أمر البناء / Output Directory فارغًا لأن الموقع HTML/CSS/JS من دون خطوة بناء، ثم **Deploy**.
6. افتح رابط Vercel، وجرّب سورة الفاتحة والصفحة 604 وتشغيل الصوت والانتقال بين الصفحات على الهاتف.

لا يلزم `npm install` ولا مفاتيح API ولا قاعدة بيانات. يمكن تشغيل نسخة محلية للتطوير بواسطة `npm start` ثم زيارة `http://localhost:3000` مع Node.js 18 أو أحدث. **الاتصال بالإنترنت ضروري لعرض صفحات القرآن وتشغيل التلاوة**.

## سلامة نص القرآن ومزامنة الصوت

- **القرآن ليس مكتوبًا يدويًا داخل هذا المشروع.** يقوم `/api/page?page=N` بجلب الآيات كما هي من مصدر [Al Quran Cloud](https://alquran.cloud/api) بنسخة `quran-uthmani`. أرقام السور والآيات وصفحاتها تأتي من المصدر نفسه. عند فشل المصدر لا يظهر نص قرآني مفترض بديل.
- تجلب `/api/timing?surah=N` توقيت التلاوة لمـاهر المعيقلي من [Kalamalah](https://huggingface.co/datasets/Kalamalah/cdn/blob/main/README.md). يُستخدم ملف الصوت المُعلن مع هذه البيانات فقط للحفاظ على التطابق الزمني، مع مطابقة فهارس الكلمات للآية المعروضة قبل تفعيل إبراز الكلمات.
- إذا تعطل توقيت Kalamalah، يتاح تشغيل بديل لآيات ماهر المعيقلي من [EveryAyah](https://everyayah.com/) دون الادعاء بتوفر تزامن على مستوى الكلمة؛ تستمر إمكانية التنقل بين الآيات.
- **مهم:** هذا مشروع جاهز كتطبيق أولي ولا يمثل مصحفًا جرى تدقيق كل حرف فيه يدويًا أو اعتمادُه من جهة رسمية. قبل النشر العام، يجب اختبار المصادر والبيانات الفعلية، وفحص نصوص صفحات مختارة ومزامنة الكلمات بصريًا/سمعيًا، ثم مراجعتها لدى مختص بعلوم القرآن. ولم يتم التحقق الحي من خوادم الصوت من بيئة إعداد المشروع.
- تخطيط النصوص **بطاقات للآيات مجمعة حسب الصفحة** وليس صورة مطابقة لصفحات المصحف المطبوع ذات الـ15 سطرًا؛ وذلك يوافق الحركة المطلوبة في الفيديو ويحافظ على تسلسل الآيات.

## ترخيص وتوثيق

التلاوات مسموعة عبر مزودين خارجيين، ولا يتم نسخ ملفات الصوت إلى المستودع. مصادر EveryAyah قد تكون حقوق تسجيلاتها غير محددة؛ راجع شروط المزود واستحصل على الإذن اللازم قبل الاستخدام التجاري أو توزيع التسجيلات. التزم بذكر المصادر والقارئ، ولا تعِد تعديل التلاوات. بيانات التلاوة تعتمد على توافر مزودي الخدمات الخارجيين.

## هيكل المشروع

- `index.html`: واجهات الموقع
- `styles.css`: التصميم المتجاوب
- `app.js`: التفاعل، التلاوة، الصفحات، المسبحة
- `article.js`: المقال الكامل
- `favicon.svg`: الأيقونة
- `api/page.js`, `api/verse.js`, `api/chapters.js`, `api/timing.js`: نقاط بيانات Vercel Serverless
- `api/_shared.js`: التحقق من استجابة المصادر الخارجية وذاكرة التخزين المؤقت على مستوى HTTP
- `dev-server.js`: تشغيل محلي بسيط
- `vercel.json`: إعداد Vercel
