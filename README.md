# موقع القرآن الكريم — تصميم مطابق للصور المرسلة

نسخة واجهة بسيطة لموقع القرآن الكريم والمقالات وسبّح. التصميم يقترب من صور المرجع: خلفية رمادية-خضراء داكنة، ثلاثة بنرات متدرجة، نص قرآن واسع، بطاقة تبرز الآية الحالية، ومسبحة دائرية كبيرة.

## التحديث على GitHub وVercel

1. فكّ الضغط عن ZIP.
2. افتح نفس مستودع GitHub الذي يتصل بمشروع Vercel الحالي.
3. اختر `Add file` ثم `Upload files`، واسحب **الملفات والمجلد `api` الموجودة داخل ZIP**. احرص على أن يكون `index.html` في جذر المستودع مباشرة، وليس داخل مجلد مضاعف.
4. إذا سألك GitHub عن الملفات الموجودة بنفس الأسماء، اعتمد استبدالها بالتعديلات الجديدة.
5. اضغط `Commit changes`. يبدأ Vercel نشر نسخة جديدة آليًا إذا ظل GitHub متصلًا به.
6. افتح رابط Vercel بعد اكتمال النشر، وجرّب كل أقسام الموقع.

لا تحتاج لإضافة متغيرات بيئة أو تثبيت حزم لإنشاء المشروع في Vercel؛ اختر Framework Preset = Other، مع بقاء Root Directory = ./ والإعدادات الافتراضية.

## الاختبار المحلي

يتطلب Node.js 18 أو أحدث:

```bash
npm start
```

ثم افتح `http://localhost:3000` في المتصفح. التلاوة وجلب المصحف يحتاجان اتصالًا بالإنترنت.

## دقة المصحف والمزامنة

- النص القرآني لا يُكتب يدويًا في الموقع: واجهة `api/page.js` ترحّل بيانات صفحة المصحف من AlQuran Cloud مع فحص التنسيق ورقم الصفحة.
- الصوت الأساسي يُجرَّب مع بيانات توقيت ماهر المعيقلي من Kalamalah؛ إذا تعذّر، يُستخدم تسجيل الآية المنفردة من EveryAyah دون اختراع توقيت كلمات.
- لا يجوز اعتبار إبراز الكلمات مضبوطًا قبل تجربة التسجيل والتوقيت الفعليين في النشر واختبارهما صفحةً صفحةً.
- المسبحة تحفظ العداد وأهداف الذكر في المتصفح المحلي للجهاز نفسه.

## أهم الملفات

- `index.html`: الأقسام والمحتوى المرئي.
- `styles.css`: واجهة الموقع المطابقة لصور المرجع.
- `app.js`: تصفح المصحف وتشغيل التلاوة وإبراز الكلمات والتسبيح.
- `article.js`: النص الكامل للمقال.
- `api/`: اتصال API مع مصادر القرآن.
